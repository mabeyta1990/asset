# ASSET: AI Engineering Pipeline

## Product Definition
ASSET is a 5-model AI engineering pipeline designed to produce audit-approved code with full provenance. It operates through five role-isolated stages: Analysis, Strategy, Scripting, Evaluation, and Trust.

## Core Value Proposition
- **High Integrity:** No model grades its own work; independence at every checkpoint.
- **Traceability:** Full provenance for every line of code produced.
- **Efficiency:** Strategic use of context caching across different AI models.
- **Safety:** Sandboxed execution in a dedicated VM environment.

## Target Use Cases
- Generating production-ready code from requirements.
- Automated code auditing and validation.
- Maintaining a canonical, approved state of a codebase.
